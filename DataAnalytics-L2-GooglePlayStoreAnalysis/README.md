# TASK 4 - Unveiling the Android App Market (Google Play Store Analysis)

**Objective:** Perform a comprehensive data analysis of the Google Play Store ecosystem — cleaning messy real-world data, exploring app categories, analysing ratings and pricing trends, and conducting sentiment analysis on user reviews.

**Tech Stack:** Python, pandas, numpy, matplotlib, seaborn, VADER, plotly, Jupyter Notebook

**Dataset:** Kaggle - Google Play Store Apps + User Reviews

**Feature Checklist Completed:**
- [x] Load the Play Store apps dataset and the user reviews dataset separately
- [x] Data cleaning: fix "Installs" stored as "10,000+" strings, handle nulls, remove duplicates
- [x] Category analysis: bar chart of app distribution; FAMILY & GAME most saturated
- [x] Ratings analysis: distribution of app ratings; average rating by category
- [x] Size and installs analysis: scatter plot of app size vs installs; no correlation found
- [x] Pricing analysis: paid vs free distribution; price distribution; revenue estimate by category
- [x] Sentiment analysis on user reviews using VADER
- [x] Sentiment by category
- [x] Interactive visualisation using plotly
- [x] Conclusion: 3 data-driven insights for new developer

**Key Insights:**
1. 92%+ apps are Free - Freemium model is best for new launch.
2. App Size doesn't affect Installs, but Rating > 4.3 does.
3. Niche categories like BEAUTY, MEDICAL have less competition and high ratings.
